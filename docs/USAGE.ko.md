# 성적표 요약 생성기 사용법

성적 관리 시스템에서 내려받은 성적 CSV 파일을 폴더에 넣고 스크립트를 실행하면, 학생별 과목 평균 · 총 평균 · 레벨 판정 결과가 담긴 요약 CSV가 만들어집니다.

---

## 사전 준비

Python 3.9 이상이 필요합니다. 터미널을 열고 아래 명령어를 입력하세요:

```
python3 --version
```

`Python 3.x.x` 같은 버전이 나오면 준비 완료입니다. 설치가 안 되어 있다면 https://www.python.org 에서 다운로드하세요. 다른 패키지는 필요 없습니다.

---

## 폴더 구조

```
desk-tools/
├── g1_5/                    ← 1~5학년용 (Track A / Track B)
│   ├── CSV/                 ← 여기에 CSV 파일을 넣으세요
│   └── generate_summary.py
├── g6/                      ← 6학년용 (Track 1 / Track 2)
│   ├── CSV/                 ← 여기에 CSV 파일을 넣으세요
│   └── generate_summary.py
└── analyze_cutlines.py      ← 선택사항: 요약 파일로 커트라인 제안
```

---

## 실행 방법

### 1단계: CSV 파일 준비

성적 데이터가 담긴 CSV 파일을 해당 학년 폴더의 `CSV` 폴더 안에 넣으세요.

- **6학년** 성적 → `g6/CSV/`
- **1~5학년** 성적 → `g1_5/CSV/`

> CSV 파일에는 반드시 `원생명`, `반명`, `시험일`(`YYYY-MM-DD`) 열이 있어야 합니다. 나머지 열은 모두 과목 점수 열로 처리됩니다.
> 여러 개의 CSV 파일을 한꺼번에 넣어도 됩니다.

각 `CSV/` 폴더에는 바로 실행해 볼 수 있도록 가상의 `sample_grades.csv`가 들어 있습니다. 실제 데이터를 처리할 때는 샘플 파일을 지우거나 옮기세요. 그대로 두면 샘플도 함께 요약됩니다.

### 2단계: 스크립트 실행

`desk-tools` 폴더에서:

**6학년:**
```
python3 g6/generate_summary.py
```

**1~5학년:**
```
python3 g1_5/generate_summary.py
```

다른 폴더에서 읽고 다른 폴더에 저장하려면:

```
python3 g1_5/generate_summary.py --csv-dir /입력/폴더 --out-dir /출력/폴더
```

### 3단계: 결과 확인

실행이 완료되면 스크립트 옆(또는 `--out-dir`)에 `_summary.csv` 파일이 생성됩니다.

- CSV 파일이 1개인 경우: `원본파일명_summary.csv`
- CSV 파일이 여러 개인 경우 (6학년만 해당): `combined_summary.csv`
- 1~5학년은 CSV 파일마다 개별 summary 파일이 생성됩니다.

이 파일을 엑셀이나 구글 스프레드시트에서 열어서 확인하세요.

같은 학생이 같은 반에서 같은 주에 두 번 이상 점수가 입력된 경우, 나중 날짜만 남기고 앞선 날짜는 `duplicate_entries.md`에 정리됩니다. 원본 시스템에서 해당 항목을 삭제하면 됩니다.

## 설정 변경 (선택사항)

각 `generate_summary.py` 파일 상단의 `SETTINGS` 부분을 수정할 수 있습니다:

| 설정 | 기본값 | 설명 |
|------|--------|------|
| `LEVELING` | `False` | `True`로 바꾸면 커트라인에 따라 UP/STAY/DOWN 판정이 적용됩니다. `False`이면 모두 "PENDING"으로 표시됩니다. |
| `MIN_TESTS` | `5` | 트랙별 최소 시험 횟수. 이 횟수 미만인 학생은 요약에서 제외됩니다. |
| `START_CUTOFF` | `None` | 예: `datetime(2026, 1, 26)`. 첫 점수가 이 날짜 이후인 학생은 제외됩니다. `None`이면 사용하지 않습니다. |
| `PARTICIP_WEIGHT` / `ACADEMIC_WEIGHT` | `0.1` / `0.9` | 총 평균에서 `Particip`(참여도) 열과 나머지 과목의 비중입니다. |
| `PARTICIP_COL` | `"Particip"` | 참여도 열의 이름입니다. 이 열이 없으면 총 평균은 과목 평균만으로 계산됩니다. |
| `TRACK_WEIGHTS` (g6만) | `{TRACK_1: 0.6, TRACK_2: 0.4}` | 두 트랙 모두 수강하는 학생의 Track 1 / Track 2 평균 비중입니다. |
| `LV_CUTLINES` | `{2: 80, 3: 70, 4: 60}` | 각 레벨별 커트라인 점수. 평균이 80점 이상이면 Lv2, 70점 이상이면 Lv3, 60점 이상이면 Lv4, 그 미만은 "P"로 판정합니다. **기본값은 자리표시용 숫자이므로 기관에 맞게 설정하세요.** |

## 출력 결과 읽는 법

요약 CSV에는 학생들이 그룹별로 정리되어 있습니다:

**6학년 (g6):**
- **주2**: Track 1과 Track 2 수업 모두 수강하는 학생 (Track 1 60% + Track 2 40% 가중 평균)
- **주1 Track 1**: Track 1 수업만 수강하는 학생
- **주1 Track 2**: Track 2 수업만 수강하는 학생

**1~5학년 (g1_5):**
- **주2**: Track A(월화수)와 Track B(목금토) 수업 모두 수강하는 학생
- **주1 Track A**: 월화수 수업만 수강하는 학생
- **주1 Track B**: 목금토 수업만 수강하는 학생

각 그룹 내에서 학생들은 총 평균 점수가 높은 순으로 정렬됩니다.

트랙 판별 방법:
- g1_5: 반명의 요일 코드로 판별합니다. 예: `G3-21M(TeacherA)`는 Track A, `G3-21TH(TeacherB)`는 Track B. M / TU / W는 Track A, TH / F / SA는 Track B입니다.
- g6: 반명이 `[E]`로 시작하면 Track 1, 아니면 괄호 안 표기로 판별합니다. 영문이면 Track 1, 한글이면 Track 2입니다.

현재 레벨 판별 방법: 반명에서 `G학년-` 바로 뒤 숫자가 레벨입니다 (`G3-21M`이면 레벨 2). 원생명에 표기가 있으면 그것이 우선합니다: `L3`은 레벨 지정, `(P)`는 P 레벨, g6에서는 `E2K3`(또는 `K3E2`), `E3`, `K2`로 트랙별 레벨을 지정합니다 (`E` 표기는 Track 1, `K` 표기는 Track 2에 해당). 이름 뒤의 `주1`과 `*`는 출력 시 제거됩니다.

---

## 커트라인 제안 (선택사항)

`analyze_cutlines.py`는 요약 CSV를 읽어 현재 레벨별 중앙값으로 커트라인을 제안하고 (상위 레벨 중앙값 70% + 하위 레벨 중앙값 30%), 그 숫자를 적용했을 때 누가 이동하는지 보여줍니다:

```
python3 analyze_cutlines.py g1_5/sample_grades_summary.csv
```

보고서는 요약 파일 옆에 `cutline_report.md`로 저장됩니다 (`--out`으로 경로 지정 가능). 사람이 결정할 때 참고하는 기술 통계일 뿐입니다.

## 문제 해결

| 문제 | 해결 방법 |
|------|-----------|
| `No CSV files found` 메시지가 나옴 | CSV 폴더(또는 `--csv-dir`) 안에 `.csv` 파일이 있는지 확인하세요 |
| `python3: command not found` | Python이 설치되어 있는지 확인하세요. 윈도우에서는 `python`으로 시도해보세요 |
| 한글이 깨져서 나옴 | 프로그램이 UTF-8과 CP949/EUC-KR을 자동으로 감지하지만, 문제가 계속되면 CSV 파일을 UTF-8로 다시 저장해보세요 |
| 특정 학생이 결과에 없음 | 시험 횟수가 `MIN_TESTS` 미만이거나 `START_CUTOFF` 이후에 시작한 학생일 수 있습니다 |
| 특정 반이 결과에 없음 (g1_5) | 반명이 `G숫자-숫자요일(...)` 형식이 아니어서 트랙을 판별하지 못한 경우입니다 |
